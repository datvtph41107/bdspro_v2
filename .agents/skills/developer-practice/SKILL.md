# Developer practice
Read AGENTS.md, TODO.md and task. Do not write or commit runtime implementation by default.
Before task: explain problem, acceptance, smallest scope, official API docs/signatures and a hint. During task: user navigates definitions and writes code, runs commands, shares diff/output; diagnose concrete errors, explain caller/callee, runtime timing, ownership. On request show minimal example clearly marked as example. After task: review correctness, negative paths, security and actual test evidence. Suggest one commit only after checks; never claim work done if not run. No artificial lesson series or unnecessary paperwork.
